# Natnael Arega — Developer Portfolio

A responsive React + Vite portfolio with plain CSS (no Tailwind).

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the `natnael-portfolio` folder in VS Code.
3. Open a terminal in that folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local address printed in the terminal (usually `http://localhost:5173`).

## Customize before publishing
- `src/main.jsx`: edit the name, About copy, project details, email, and social profile links.
- Replace project concept cards with genuine screenshots and real demo/repository links.
- Update the title and description in `index.html`.
- Contact email currently uses `natnaelarega9@gmail.com`.

## Build for deployment
Run `npm run build`. Vite creates a `dist` folder that can be deployed to a static hosting service.

Project cards are presented as practice concepts and should not be described as finished client work unless that is accurate.
